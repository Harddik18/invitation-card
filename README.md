# 💌 Luxury Digital Invitation Card

A modern, interactive digital invitation card web application built with **Antigravity AI** for **Mandani Hardik**.

## ✨ Features
- **Royal Wax Seal Opening**: Realistic 3D wax seal and envelope opening animation.
- **Live Countdown Timer**: Dynamic real-time timer counting down to event date.
- **Interactive RSVP Modal**: Guest attendance confirmation with instant confetti celebration.
- **Responsive Mobile Layout**: Fits perfectly across iPhones, Android phones, and desktops.
- **Location & Google Maps Integration**: Direct button for guests to find venue directions.
